# AI-architecture 文档规范（自动加载于 docs/ 目录及 .md 文件）

## 编号/标识符规则

### 追溯顺序（严格按此顺序，不可跳过）
1. CLAUDE.md 中的术语表和规范章节
2. .claude/rules/ 中的规则定义
3. 已有产出物中已确认的标识符
4. 新建（仅当前三步都找不到时）

### 禁止事项
- 自创标识符：未在权威来源中找到来源
- 标识符重复：同一标识符用于不同实体
- 格式偏离：标识符必须遵循 `[AI-ARCH]-[类别]-[序号]` 格式

## 文档结构要求

每种产出物目录应包含：
- README.md — 目录说明和索引
- 核心文档（按需组织）
- 交叉引用清晰，链接有效

## 模板驱动

如果项目定义了模板目录，所有产出物必须基于模板生成。
生成前检查模板版本是否为最新。

## 修改高复用产出的约束

修改以下产出前，必须评估影响范围：
- 规范/规则文件（被多处引用）→ 检查所有关联产出
- 术语表/Terminology（全局影响）→ 全量搜索替换
